# Инженер по тестированию: от новичка до автоматизатора

Репозиторий с практическими работами, выполненными в рамках обучения на курсе **«Инженер по тестированию: от новичка до автоматизатора»** в Яндекс Практикуме.

В репозитории собраны учебные проекты по ручному и автоматизированному тестированию: от регрессионного тестирования и тест-дизайна до разработки автотестов на Java, тестирования API и UI.

## Содержание

### Ручное тестирование

- Регрессионное тестирование и ретестирование багов веб-приложений
- Тест-анализ и тест-дизайн
- Классы эквивалентности
- Граничные значения
- Тест-кейсы
- Чек-листы
- Функциональное тестирование
- Тестирование вёрстки
- Тестирование мобильных приложений
- Тестирование API
- SQL и основы работы с базами данных

### Автоматизация тестирования

- Java
- JUnit 4
- Unit-тестирование
- Mockito
- Selenium
- UI-тестирование
- Page Object Model (POM)
- Сериализация
- REST Assured
- JaCoCo
- Allure
- Maven
- Git и GitHub

## Структура репозитория

Все практические работы расположены в папке [`sprint-projects`](./sprint-projects) и разделены по спринтам.

| Спринт | Тема | Что было сделано |
|---|---|---|
| 01 | Регрессионное тестирование и ретест багов веб-приложений | Выполнение регрессионных проверок по готовым тестам, ретест исправленных багов и работа с баг-репортами |
| 02 | Тестирование фичи: от тест-анализа до баг-репорта | Тест-анализ, классы эквивалентности, граничные значения, тест-кейсы, функциональное тестирование и баг-репорты |
| 03 | Расширенное тестирование веб-приложений | Чек-листы для проверки логики и вёрстки, дополнительные тест-кейсы и итоговый отчёт о тестировании |
| 04 | Тестирование мобильных приложений | Функциональное и регрессионное тестирование мобильного приложения «Яндекс Метро» |
| 05 | Тестирование API | Ручное тестирование API с помощью Postman и анализ ответов сервера |
| 06 | Основы баз данных | Написание SQL-запросов для работы с базой данных |
| 07 | Введение в Java | Основы Java и разработка первой программы |
| 08 | Java: базовые конструкции | Работа с базовыми конструкциями Java, классами и объектами |
| 09 | Введение в юнит-тестирование | Написание простых unit-тестов для Java-классов |
| 10 | UI-тестирование | Автоматизация UI-тестов с использованием Selenium, Java, сериализации и POM |
| 11 | Java: продвинутый блок | Работа с наследованием и другими возможностями объектно-ориентированного программирования |
| 12 | Юнит-тестирование | Разработка unit-тестов с использованием JUnit и Mockito, анализ покрытия кода с JaCoCo |
| 13 | Тестирование API | Автоматизация API-тестов с использованием REST Assured, Maven и Allure |
| Диплом | Итоговый проект | Ручное и автоматизированное тестирование веб-приложения, мобильного приложения и API |

## Дипломный проект

### 1. Ручное тестирование

Выполнены задания:

- **Проектирование тестов и тестирование веб-приложения**
- **Проектирование тестов для мобильного приложения**

В рамках заданий выполнялись:

- тест-анализ;
- составление чек-листов и тест-кейсов;
- проверка логики приложения;
- проверка валидации полей;
- применение классов эквивалентности и граничных значений;
- оформление результатов тестирования.

### 2. Автоматизация тестирования

Выполнены задания:

- **Unit-тесты**
- **Автотесты для API**
- **Автотесты для UI**

Для автоматизации использовались:

- Java
- JUnit 4
- Mockito
- Selenium
- REST Assured
- Maven
- JaCoCo
- Allure
- Git / GitHub
